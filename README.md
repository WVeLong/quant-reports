# quant-reports

A quantitative research knowledge base covering algorithm papers, factor mining, high-frequency factor construction, portfolio construction, risk models, symbolic/GP search, and automated research.

本仓库包含“量化研究知识库”静态网站。

入口：https://wvelong.github.io/quant-reports/

目录：

- `categories/`: 按阅读主题分类的网页入口
- `notes/`: 每篇报告的阅读问题页
- `pdf/`: 按分类整理的完整研报 PDF
- `research-map.html`: 74 篇论文与研报的混合架构研读地图
- `research_map.json`: 论文分类、优先级、研究重点与访问状态索引
- `papers/`: 新增论文 PDF，按研究任务分类
- `reading-map/`: 研读地图的 PDF 与 Word 原稿
- `all-reports.html`: 服务器历史全量研报库入口
- `reports/`: 从 `/mnt/research/研报/` 同步的全量研报文件
- `reports_manifest.json` / `reports_manifest.csv`: 全量研报索引数据
- `download_manifest.csv`: 匹配和下载清单
- `manifest.json`: 网页索引数据
